# ML Lab 3 — Ticket Escalation

Beginner-level work for the ticket escalation classification lab.

## Files
- `lab3_answers.md`: answers and results.
- `analysis.py`: preprocessing, model training, evaluation, threshold comparison, and cross-validation.

## Run
Put the lab's `classification_escalation.csv` dataset in this folder, then install:

```bash
pip install pandas scikit-learn
```

Run:

```bash
python analysis.py
```
